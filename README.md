JavaScript Assignments and Mini Project

📌 Project Overview

This repository contains six practical JavaScript assignments and a capstone mini project developed as part of the JavaScript learning curriculum. It covers fundamental JavaScript concepts through simple examples and practical implementation.

The final project, Interactive Product Inventory and Analytics Dashboard, allows users to add products, view their prices and categories, calculate inventory value, and generate a formatted product report.

🎯 Objectives

- Understand JavaScript variables and data types.
- Practice operators, expressions, and user input.
- Implement conditional statements and loops.
- Learn functions, parameters, and variable scope.
- Work with arrays, objects, and array methods.
- Apply JavaScript concepts in a practical mini project.

📚 Assignments

Assignment 1: Variables and Data Types

Uses "var", "let", and "const" to store values and demonstrates the "typeof" operator.

Assignment 2: Operators and Input Handling

Accepts a bill amount and tip percentage, converts input into numbers, and calculates the final bill.

Assignment 3: Conditional Logic

Uses "if...else", "switch", and the ternary operator to determine a student's grade and pass status.

Assignment 4: Loop Control Structures

Demonstrates "for", "while", and "do...while" loops, along with "break" and "continue".

Assignment 5: Functions and Scope

Demonstrates regular functions, arrow functions, default parameters, and block scope.

Assignment 6: Arrays and Objects

Uses product objects and the "forEach()", "filter()", and "map()" methods to display and transform product information.

🚀 Capstone Mini Project

Interactive Product Inventory and Analytics Dashboard

The mini project combines the concepts learned in the assignments into a practical inventory application.

Features

- Add products with a name and price.
- Validate product details before adding them.
- Assign Budget, Standard, or Premium categories based on price.
- Display all products in an inventory table.
- Calculate the total inventory value.
- Find products priced below $200.
- Generate a formatted report of product names and prices.
- Display inventory results in the browser console.

Technologies Used

- HTML5
- CSS3
- JavaScript

⚙️ How to Run the Project

1. Download or clone this repository.
2. Extract the ZIP file if downloaded.
3. Open the project folder in Visual Studio Code.
4. Open the root "index.html" file in a web browser.
5. Select an assignment to view its source code.
6. To execute an assignment, run its JavaScript in a browser context. Assignments that use "prompt()" require browser input dialogs.
7. Open "mini_project/index.html" to use the interactive inventory dashboard.

For console output, open the browser Developer Tools using "F12" and select the Console tab.
