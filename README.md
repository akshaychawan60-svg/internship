JavaScript Assignments and Mini Project
=========================================

This folder contains the six assignments from the JavaScript guide and the final mini project.

How to open the project
-----------------------
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser.
4. For assignment output, open the browser console (press F12, then choose Console).
5. Open mini_project/index.html to use the product inventory application.

The code uses simple variable names, comments, and clear steps so a student can read it and understand what each part does.

Assignments
-----------
1. Variables and data types
2. Bill and tip calculator
3. Test score and grade
4. Loops
5. Functions and scope
6. Products, arrays, and objects

Mini project
------------
Add a product name and price to the inventory. The page shows each product's category, the total inventory value, products under $200, and a formatted report.

Note: The assignments that use prompt() should be run in a browser page, not by double-clicking the .js file.
